## OCR 原型补充

按 agent/README.md 执行 ocr_probe.py。用户恢复窗口、打开文件传输助手，并人工在输入区留 OCR_TEST_20261004；本地 RapidOCR 的两帧标题、标记和快照一致性检查已通过。原生 Windows OCR 输入标记下划线缺失，未作默认引擎。

真实未验项仍包括：切到错会话的阻断回归、窗口改变后的阻断回归、锁屏、两私聊的收发方向与重复消息、语音和 4 小时观察。相关边界逻辑已由假数据检查，但不能替代真实桌面验收。详见 docs/acceptance/ocr-readonly-report.md。
